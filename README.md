# MobilePDF - 纯前端 PDF 编辑与解密工具 (Pure Frontend Web App)

专为手机端与桌面端设计的纯前端 PDF 文档编辑、解密与隐私打码 Web App。所有解析、OCR 识别、图层交互与合成导出均 **100% 在本地浏览器内安全完成**，不上传任何服务器。

---

## 🌟 核心功能

1. **密码解锁与解密导出**
   - 自动检测受密码保护的 PDF 文档并触发密码解锁弹窗。
   - 输入访问密码渲染后，导出时自动重构为免密码 PDF，方便在移动端及常用阅读器中打开。

2. **点字即改 & 一键转 Word 模式**
   - 基于 PDF.js 高清渲染底层文档 + Fabric.js 顶层交互画布，实现精准坐标对齐。
   - 支持直接点击文档文字或框选区域进行原位文本修改，支持字体族切换（默认无衬线 / Arial / 衬线宋体 / 等宽字体）、字号、加粗（`B`）、斜体（`I`）、文本颜色及纸张底色匹配。

3. **选中移动 / 批量替换 / 实时撤销栈**
   - 支持「浏览」「选中」「编辑」三模式快速切换，手机端单指拖拽与双指缩放零手势冲突。
   - 内置逐页操作历史快照撤销栈（支持顶部「撤销」按钮及 `Ctrl+Z` / `Cmd+Z`），连带恢复联动遮罩与编辑内容。
   - 支持全文/当前页「一键批量查找替换」（`Ctrl+H`），以及页码点击快速跳转。

4. **本地 OCR 识别、旋转与隐私打码**
   - 支持导入 JPG / PNG / WebP 图片或扫描型 PDF，提供页面顺时针 90° 旋转、2.0x 高清本地 Tesseract OCR 识别（支持英文数字及中英混合）。
   - 「遮罩打码」工具内置「隐私涂黑（`#000000`）」与纸色覆盖色块，方便在分享文档前一键遮挡敏感信息。

5. **双引擎无损导出 & 本地草稿暂存**
   - 普通未旋转 PDF 采用原矢量页叠加导出，保留原文档矢量清晰度；加密或旋转页面自动高清重构对齐导出。
   - 编辑进度通过浏览器 IndexedDB 自动暂存本地草稿，防止误关页面丢失修改。

## 🛡️ 隐私与合规使用声明

- **纯本地处理**：您的所有 PDF 与图片文件仅在本地浏览器内存中处理，不会上传至任何第三方或云端服务器。
- **合规使用**：本工具严格用于合法的个人与办公文档编辑、表单填写、学习批注、电子签名及敏感信息打码，**严禁用于伪造或篡改身份证件、官方证明或金融法律票据**。

## 🚀 本地开发与上线部署

在项目根目录下启动轻量静态服务器：

```bash
npm start
# 或
npx serve . -l 3000
```

打开浏览器访问 `http://localhost:3000` 即可体验内置样例：
- **商务合作协议样例** (`./sample/contract-sample.pdf`)：体验点击改字、字体样式调整、金额批量替换、隐私打码与电子签名。
- **密码加密测试样例** (`./sample/encrypted-sample.pdf`)：测试密码解锁（密码：`test`）与免密导出功能。

### Vercel 一键部署
本项目为零构建纯静态项目（`index.html` + `style.css` + `app.js` + `vercel.json`）：

```bash
vercel --prod
```
