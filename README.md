# MobilePDF 原样修改器 (Pure Frontend Web App)

专为手机端和桌面端设计的纯前端 PDF 原样修改与解密工具。无需后端服务器支持，所有 PDF 解析、解密、图层交互与合成导出均在浏览器端（Client-side）安全完成。

---

## 🌟 核心特性

1. **密码解锁与解密导出**
   - 自动检测受密码保护的 PDF 文件并触发极简密码解锁弹窗。
   - 输入密码后解密渲染，并在导出时自动清除密码限制，生成公开可直接打开的新 PDF。

2. **原样擦除与改字（Cover & Edit）**
   - PDF.js 高清渲染底层文档 + Fabric.js 顶层透明交互画布，实现 100% 像素级对齐。
   - 手指/鼠标框选任意文字区域，自动提取周边背景底色生成遮罩块，并在原位置无缝生成可编辑文本框。
   - 支持插入多行文字、自定义透明底电子手写签名、印章图片上传与画笔批注涂鸦。

3. **移动端优先适配（Mobile-First）**
   - 底部工具栏单手拇指触达优化，大触控尺寸设计。
   - 支持“浏览平移模式（Hand Tool）”与“编辑修改模式（Edit Tool）”一键切换，彻底杜绝手机放大修改时手势冲突。
   - 右上角常驻快捷缩放 HUD（+、-、适应屏幕宽度、200% 局部特写），同时支持双指捏合缩放（Pinch-to-zoom）。

4. **无损矢量与解密双引擎导出**
   - 未加密 PDF：直接在原矢量页精准叠加修改层，保留原版清晰度与全部未修改文字矢量。
   - 加密 PDF：解密重构并生成免密 PDF，确保在微信、QQ、各类手机阅读器中无障碍秒开。

## 🚀 本地预览与测试

在项目根目录下启动轻量 Web 服务器：

```bash
# 使用 npx 快速启动本地预览
npx serve . -l 3000
```

打开浏览器访问 `http://localhost:3000` 即可开始测试。

内置测试样例：
- **商务合作协议样例**：快速测试原样擦除改字、修改金额与插入电子签名。
- **密码加密测试样例**：测试密码解锁（密码为 `test`）及免密导出功能。

## ⚡ 一键部署到 Vercel

本项目为零构建纯静态项目（纯 HTML + Tailwind CSS + JS），一键即可部署到 Vercel：

### 方法一：使用 Vercel CLI（推荐）

1. 全局安装 Vercel CLI（如已安装可跳过）：
   ```bash
   npm i -g vercel
   ```

2. 在项目目录中直接运行：
   ```bash
   vercel
   ```
   按照终端提示直接回车确认即可获得预览链接。

3. 部署到生产环境（Production）：
   ```bash
   vercel --prod
   ```

### 方法二：Git 仓库导入
直接将代码推送到 GitHub / GitLab / Bitbucket，在 [Vercel 控制台](https://vercel.com/new) 点击 `Import Project`，框架预设选择 `Other` 即可自动完成部署。
